## Fruit Salad Application 🍒
## Overview 

A simple front-end fruit salad API that allows you to search for specific fruit, and allows the user to add, remove, and view calories for a specific fruit. This can also tally up to see the total calories in multiple fruit.

## Getting Started

### Prerequisites 

- __Node.js__

- __npm__


### Installation requirements
1. Clone the repo by running:  `git clone https://github.com/kimlxnh/fruit-salad-application`

2. `cd` into the folder

3. Install all the dependencies by running `npm install` on your terminal
    - This project uses:

        - __watchify__

4. Run the server
    - Run `npm run dev` to run the server in development mode
